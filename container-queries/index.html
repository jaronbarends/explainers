Container queries basics

The element you want to control needs to have a container with container-type property set to size or inline-size. Container queries use the container's content-box for its size, so don't give the container any border or padding.

(In these examples I have given them a dashed border and padding for easier identification; I have subtracted those values in the boxes showing the containers' widths)

Most cases: container-type: inline-size

Item

Most regular use case: only let the size along the inline-axis to determine the styling, and don't take the size along the block-axis into account.

Use container-type: inline-size 

<div class="item-container">
  <div class="item">Item</div>
</div>

.item-container {
  container-type: inline-size;
}

.item {
  border-color: var(--color-secondary);
  background-color: var(--bg-color-secondary);
}

@container (min-width: 50rem) {
  .item {
    border-color: var(--color-primary);
    background-color: var(--bg-color-primary);
  }
}

Fixed height: container-type: size

Item

Item in .item-container-no-height with height: auto

Container needs to have a set height (either set explicitly, or implicitly in case of grid). Here the div.resizer has a fixed height; div.item-container gets 100% of that.

When no height is set on the container with container-type: size, the container will shrink to a height of 0. That is how size-containment works: it was invented to inform the browser that it can ignore the element's content for layout calculations, so if you don't specify a height, it will be 0. Horizontal container-queries will still work. 

.item-container {
  container-type: size;
  height: 100%;
}

.item {
  height: 100%;
  border-color: var(--color-secondary);
  background-color: var(--bg-color-secondary);
}

@container (min-width: 30rem) {
  .item {
    border-color: var(--color-primary);
    background-color: var(--bg-color-primary);
  }
}

@container (min-height: 10rem) {
  .item {
    background: linear-gradient(var(--bg-color-secondary), var(--bg-color-primary));
  }
}

Each grid-cell acts as a container, and needs a child element that can be styled. The containers need to have a set height. That can be done by setting a fixed height on the grid-template-rows, or you can use fr units for grid-template-rows when the grid itself has a fixed height.
Here the div.resizer has a fixed height; div.grid gets 100% of that. 

.resizer {
  height: 20rem;
}
.grid {
  display: grid;
  height: 100%;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: 2fr 1fr;
}

.item-container {
  container-type: size;

Nested containers

If you want to query a container that is not an element's nearest container-ancestor, give that container a container-name

In the example, only the profile card inside the sidebar hides its avatar when the sidebar gets below a certain width. 

<div class="sidebar">
  <div class="profile-container">
    <div class="profile-card">
      <div class="avatar">…</div>
      <div class="user-info">…</div>
    </div>
  </div>
</div>

@container (max-width: 20rem) {
  .profile {
    flex-direction: column;
    align-items: center;
  }

  .user-info {
    text-align: center;
  }
}

.sidebar {
  container-type: inline-size;
  container-name: sidebar;
}

@container sidebar (max-width: 15rem) {
  .avatar {
    display: none;
  }
}

@container sidebar {
  .avatar-img {
    background-color: var(--color-primary);
  }
}

I can't really think of a practical use case where you would want to query a higher ancestor, but it's good to know it's possible 😉
You can also use the @container with the container name without a size query, as I've done here for the avatar's color. The only advantage for doing that instead of using .sidebar .avatar-img as selector, is that @container has a specificity of 0.

Similar to viewport-units, we have container query units

  • cqi: 1% of container's inline size
  • cqb: 1% of container's block size

Also available: cqw (width), cqh (height), cqmin (min of cqi and cqb), cqmax. 

.item {
  font-size: max(1.25rem, 1rem + 2cqi);
  border-radius: 2cqi;
}
