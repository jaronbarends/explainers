Container queries basics

The element you want to control needs to have a container with container-type property set to size or inline-size. The container should be representative for the element's queried dimension(s), so don't give the container any border or padding.
(In these examples I have given them a dashed border and padding for easier identification)

Most cases: container-type: inline-size

Item

Most regular use case: only let the size along the inline-axis to determine the styling, and don't take the size along the block-axis into account.

Use container-type: inline-size 

<div class="item-container">
  <div class="item">Item</div>
</div>

.item-container {
  container-type: inline-size;
}

.item {
  border-color: var(--color-secondary);
  background-color: var(--bg-color-secondary);
}

@container (min-width: 50rem) {
  .item {
    border-color: var(--color-primary);
    background-color: var(--bg-color-primary);
  }
}

Fixed height: container-type: size

Item

Item in .item-container-no-height with height: auto

Container needs to have a set height (either set explicitly, or implicitly in case of grid). Here the div.resizer has a fixed height; div.item-container gets 100% of that.

When no height is set on the container with container-type: size, the container will shrink to a height of 0. That is how size-containment works: it was invented to inform the browser that it can ignore the element's content for layout calculations, so if you don't specify a height, it will be 0. Horizontal container-queries will still work. 

.item-container {
  container-type: size;
  height: 100%;
}

.item {
  height: 100%;
  border-color: var(--color-secondary);
  background-color: var(--bg-color-secondary);
}

@container (min-width: 30rem) {
  .item {
    border-color: var(--color-primary);
    background-color: var(--bg-color-primary);
  }
}

@container (min-height: 10rem) {
  .item {
    background: linear-gradient(var(--bg-color-secondary), var(--bg-color-primary));
  }
}
