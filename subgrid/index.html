If you make the grid responsive with grid-template-columns: repeat(auto-fit(...)), you can no longer use grid-row: 1/-1 (or something like grid-row: 1/5). If you do that, you say that the rows must be on the explicit grid. Use grid-row: span x instead. That lets the browser's auto-placement algorithm decide where each item starts, so items can wrap to new rows normally. You should also use grid-auto-rows instead of grid-template-rows, because with auto-fit, all items are placed on the implicit grid.

(This is normal grid behavior and has nothing to do with subgrid. If you remove display: grid from .teaser-item, it behaves the same.) 

.teaser-list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(12rem, 1fr));
  grid-auto-rows: auto auto 1fr auto;
}

.teaser-item {
  display: grid;
  grid-template-rows: subgrid;
  grid-row: span 4;
}

When you want to use the subgrid in nested children, you give every element in the nesting hierarchy display: grid and grid-template-rows: subgrid. And then you specify the correct span for each of these element's grid-row. 

<li class="teaser-item">
    <div class="teaser-media">
      <div class="teaser-img"></div>
    </div>
    <div class="teaser-content">
      <h4>Title</h4>
      <p>Description</p>
      <button>Click me!</button>
    </div>
  </li>
  
.teaser-item,
.teaser-media,
.teaser-content {
  display: grid;
  grid-template-rows: subgrid;
}
.teaser-item {
  grid-row: span 4;
}
.teaser-media {
  grid-row: span 1;
}
.teaser-content {
  grid-row: span 3;
}

On each item, define both grid-template-rows: subgrid and grid-template-columns: subgrid, and set the appropriate value for grid-row's and grid-column's span.

No repeat(auto-fit, minmax(…))

Because we now have two columns for every teaser, we can no longer use grid-template-columns: repeat(auto-fit, minmax(…));, since auto-fit can only be used with one value. So we have to return to something like grid-template-columns: repeat(3, 2fr 3fr);, and adjust the number of repeats based on media queries or content queries.

fr units vs auto

if you use fr units for rows or columns with subgrid, those fr units will be identical for all rows and columns. If you use auto, the size will be determined on a per-row basis. In the example, the ps with "I'm an intro text" have a height of 1fr. In teasers 4 and 5, the ps are as high as those in 1, 2 and 3, even their row doesn't need that height. The Description's row has a height of auto; those in items 1,2 and 3 are lower than those in 4 and 5.
