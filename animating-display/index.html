Animating with display

TL;DR: add 3 things

To make the element transition on entry and exit when toggling display:

  1. Add @starting-style to the element's visible state
  2. Add transition-property: display to the element
  3. Add transition-behavior: allow-discrete to the element
.some-element {
  display: none;
  opacity: 0;
  transition: 0.5s ease-in-out;
  transition-property: opacity, display;
  transition-behavior: allow-discrete;
  
  &.is-visible {
    display: block;
    opacity: 1;
  }
}

@starting-style {
  .some-element.is-visible {
    opacity: 0; 
  }
}

About discrete properties

Some properties in css are discrete, meaning they can't interpolate between values. You can think of these like an on/off switch. Examples include display, visibility, font-family, mix-blend-mode.

Why you can't just use transition on display

When you set display: none; on an element, the browser completely removes the element from its render tree. Because the element is no longer visually rendered or taking up physical space, a transition or animation has no value to work with.

Step by step

Default display toggle — no transition

Default: switch between display: none; and display: block; is immediate 

/* Does not transition*/
.box {
  display: none;
  ...
  transition: 0.5s ease-in-out;
  transition-property: opacity, transform;
  opacity: 0;
  transform: translateY(50%);

  &.is-visible {
    display: block;
    transform: translateY(0);
    opacity: 1;
  }
}

Transition on entry only: add @starting-style

When you add a @starting-style, you define the before first paint state of an element. (Make sure to apply this to .box.is-visible, and not to .box; otherwise, the styles of &.is-visible will overrule the starting styles because of higher specificity.)

Note that we do not transition display here. The flip from display: none; to display: block; is still immediate. The @starting-style then gives opacity and transform their before-first-paint values, and those two properties transition normally. The switch back to display: none; is still immediate too, so there's nothing left to animate. 

/* Will transition on entry only */
.box {
  display: none;
  ...
  transition: 0.5s ease-in-out;
  transition-property: opacity, transform;
  opacity: 0;
  transform: translateY(50%);

  &.is-visible {
    display: block;
    transform: translateY(0);
    opacity: 1;
  }
}

@starting-style {
  .box.is-visible {
    opacity: 0;
    transform: translateY(50%);
  }
}

Transition on entry and exit: add transition-property: display and transition-behavior: allow-discrete

To make the element transition on exit, we need to add display to the transition-property list. And because display is a discrete property, we need to add transition-behavior: allow-discrete as well. 

/* Will transition on entry and exit */
.box {
  transition: 0.5s ease-in-out;
  /* allow-discrete can also be added to the shorthand, but then you'll also need to add a fallback-shorthand for browsers that don't support it */
  transition-behavior: allow-discrete;
  transition-property: opacity, transform, display;
  opacity: 0;
  transform: translateY(50%);
  
  &.is-visible {
    display: block;
    transform: translateY(0);
    opacity: 1;
  }
}

@starting-style {
  .box.is-visible {
    opacity: 0;
    transform: translateY(50%);
  }
}

Using keyframe animations

For keyframe animations, you don't need to use @starting-style, transition-property: display or allow-discrete. For entry animations, add display: block on the first keyframe. For exit animations, you need to add display: none on the last keyframe.

Entry animations work in all major browsers; exit animations have limited support. 

@keyframes entry-animation {
  0% {
    display: block;
    opacity: 0;
  }
  50% {
    opacity: 1;
    rotate: 30deg;
  }
  100% {
    rotate: 0deg;
  }
}

@keyframes exit-animation {
  0% {
    display: block;
    opacity: 1;
  }
  50% {
    opacity: 1;
    rotate: 30deg;
  }
  100% {
    display: none;
    opacity: 0;
    rotate: 0deg;
  }
}

.box {
  display: none;

  &.is-visible {
    display: block;
    animation: entry-animation 0.5s ease-in-out forwards;
  }

  &.is-hidden {
    animation: exit-animation 0.5s ease-in-out forwards;
  }
}
