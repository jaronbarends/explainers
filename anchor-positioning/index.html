Anchor positioning

Anchor positioning basics

Anchor
I'm the positioned element
  • Create anchor element with anchor-name property (dashed ident)
  • Pull positioned element out of document flow with position: fixed or position: absolute
  • Tie positioned element to anchor element with position-anchor
  • Set position with position-area or anchor()
  • Anchor can have multiple positioned elements
<div class="anchor-elm">Anchor</div>
<div class="positioned-elm">I'm the positioned element</div>
.anchor-elm {
  anchor-name: --sample-basics-anchor;
}

.positioned-elm {
  position: fixed;
  position-anchor: --sample-basics-anchor;
  position-area: bottom center;
}

When a page contains multiple anchors with the same anchor-name, a positioned element that is associated with that anchor name (by its position-anchor property) will be tethered to the last anchor element in the source order.

To manage this, you can define an anchor-scope on an anchor's ancestor.

  • anchor-scope is defined on an anchor's ancestor
  • Only positioned elements inside the same ancestor are allowed to tether to the specified anchor names
  • Scope can define all anchor names (anchor-scope: all) or only specific ones (anchor-scope: --my-anchor, --another-anchor) to be scoped

This is very useful for components that may occur multiple times on a page (or pages like this one where I don't want to have to come up with a unique name for every anchor). 

<div class="anchor-scope">
  <div class="anchor-elm1">Anchor 1 …</div>
  <div class="anchor-elm2">Anchor 2 …</div> </div>

  <div class="positioned-elm--anchor1-inside">…</div>
  <div class="positioned-elm--anchor2-inside">…</div>
</div>

<div class="positioned-elm--anchor1-outside">…</div>
<div class="positioned-elm--anchor2-outside">…</div>

  anchor-scope: --scoped-anchor;

Set position with position-area

  • Uses 9-cell grid based on the size of the anchor and the positioned element (each positioned element uses its own grid, not influenced by other positioned elements' sizes)
  • Physical (top, left) or logical (block-start, inline-end) values
  • Missing values will be set to center
  • Use only physical (e.g. top right) or logical (e.g. block-start inline-end) values; mixing them (e.g. top inline-end) does not work
  • span-… means "center + specified value" 
.anchor-elm {
    anchor-name: --sample-position-area-anchor;
  }

  .positioned-elm {
    position: fixed;
    position-anchor: --sample-position-area-anchor;
  }

  .positioned-elm--top {
    position-area: top; /* same as top center */
  }

  .positioned-elm--span-bottom-right {
    max-width: 6rem; /* without max-width, elm will run on one line, so you won't see effect of span */
    position-area: span-bottom right;
  }

  .positioned-elm--bottom-left {
    position-area: bottom left;
  }

Set position with the anchor() function

Anchor
top: anchor(top);
left: anchor(right);
bottom: anchor(center);
left: anchor(75%);
top: calc(anchor(center) + 1rem);
left: calc(anchor(left) + 1rem);
bottom: anchor(bottom);
right: anchor(right);

Syntax: <inset-value>: anchor(<anchor-name> <anchor-side>)

  • Positions the positioned element relative to an anchor element
  • You can usually omit <anchor-name>. Element will then be positioned relative to its associated anchor element. (You only need to specify <anchor-name> if you want to position the element relative to another anchor element than its associated anchor element. Can't think of a use case for that)
  • <anchor-side> can also be center or a percentage of the anchor's width or height
  • anchor() returns a value, so you can use it in calc
