Anchor positioning

Anchor positioning basics

Tooltip-like positioned element

Anchor
I'm the positioned element
  • Create anchor element with anchor-name property (dashed ident)
  • Pull positioned element out of document flow with position: fixed or position: absolute
  • Tie positioned element to anchor element with position-anchor
  • Set position with position-area
  • Anchor can have multiple positioned elements
<div class="anchor-elm">Anchor</div>
<div class="positioned-elm">I'm the positioned element</div>
.anchor-elm {
  anchor-name: --sample-basics-anchor;
}

.positioned-elm {
  position: fixed;
  position-anchor: --sample-basics-anchor;
  position-area: bottom center;
}

position-area

  • Uses 9-cell grid based on the size of the anchor and the positioned element (each positioned element uses its own grid, not influenced by other positioned elements' sizes)
  • Physical (top, left) or logical (block-start, inline-end) values
  • Missing values will be set to center
  • Use only physical (e.g. top right) or logical (e.g. block-start inline-end) values; mixing them (e.g. top inline-end) does not work
  • span-… means "center + specified value" 
.anchor-elm {
    anchor-name: --sample-position-area-anchor;
  }

  .positioned-elm {
    position: fixed;
    position-anchor: --sample-position-area-anchor;
  }

  .positioned-elm--top {
    position-area: top; /* same as top center */
  }

  .positioned-elm--span-bottom-right {
    max-width: 6rem; /* without max-width, elm will run on one line, so you won't see effect of span */
    position-area: span-bottom right;
  }

  .positioned-elm--bottom-left {
    position-area: bottom left;
  }
